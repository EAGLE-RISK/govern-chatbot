# Create a Risk Profile

Define the profile to which the risk to be created will be associated based on its type and department.

- **Niveau :** Intermediate
- **Durée de lecture :** 10 min
- **Tags :** Profile, Matrix, Assessment


## What is a Risk Profile?

A **risk profile** defines:
the profile to which the risk to be created will be associated based on its type, its department

## Steps to Create a Profile

**Location**: Risk Management → Risk Profiles → Create

**Step 1: General Information**
1. Click **"Create a profile"**
2. Fill in the fields:
- **Profile name**: Ex: "Operational Risk Profile"
- **Description**: Description of the profile and its usage
- **Department**: Ex: "IT"
- **Activity**: Pre-selected activity of this department
- **Owner**: Ex: "IT"
3. Click **"Next"**

**Step 2: Save**
1. Verify all configurations
2. Click **"Save"**
3. The profile is now available for creating risks

> **Tip**: Create a profile per risk type (operational, financial, strategic) for better organization.
