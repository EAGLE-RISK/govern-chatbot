# Create a Mitigation Action

Plan and track actions to reduce identified risks.

- **Niveau :** Intermediate
- **Durée de lecture :** 20 min
- **Tags :** Action, Mitigation, Planning


## What is a Mitigation Action?

A **mitigation action** is a corrective or preventive measure to reduce a risk.

## Steps to Create an Action

**Location** : Risk Management → Mitigation Actions → Create

**Step 1: Basic Information**
1. Click **"Create an action"**
2. Fill in the fields:
   - **Action name** : Ex: "Implement automatic backup system"
   - **Description** : Detailed description
   - **Associated risk** : Select the concerned risk
   - **Responsible** : Person in charge of the action
   - **Due date** : Completion deadline

**Step 2: Planning**
1. **Priority** :
   - Very high, High, Medium, Low
2. **Initial status** :
   - Planned, In progress, Completed, Cancelled
3. **Estimated budget** (optional)
4. **Required resources** (optional)

**Step 3: Save**
1. Verify information
2. Click **"Create the action"**

## Track an Action

Once created, you can:
- Update status (In progress → Completed)
- Add comments
- Attach documents
- Notify stakeholders
