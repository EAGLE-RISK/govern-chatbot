# Planifier une Évaluation

Organiser des évaluations de contrôles et audits pour assurer la conformité.

- **Niveau :** Avancé
- **Durée de lecture :** 35 min
- **Tags :** Évaluation, Audit, Conformité


## Qu'est-ce qu'une Évaluation ?

Une **évaluation** est un processus de revue formelle des risques et contrôles.

## Types d'Évaluations

1. **Évaluation de Contrôles** :
   - Test de l'efficacité des contrôles
   - Vérification de la conformité

2. **Évaluation - Audit** :
   - Audit interne ou externe
   - Vérification réglementaire

## Étapes pour Planifier une Évaluation

**Localisation** : Gestion des Risques → Évaluations → Créer

**Étape 1 : Informations Générales**
1. Cliquez sur **"Créer une évaluation"**
2. Remplissez les champs :
   - **Titre** : Ex: "Évaluation trimestrielle des contrôles IT"
   - **Description** : Description de l'évaluation
   - **Type d'évaluation** :
     - Évaluation interne
     - Évaluation externe (Audit)
   - **Risque associé** : Sélectionnez le risque à évaluer

**Étape 2 : Planification**
1. **Date de début** : Date de démarrage
2. **Date de fin** : Date de clôture prévue
3. **Évaluateur** : Personne responsable
4. **Contrôles à évaluer** : Sélectionnez les contrôles concernés

**Étape 3 : Enregistrer**
1. Vérifiez les informations
2. Cliquez sur **"Créer l'évaluation"**

## Réaliser une Évaluation

Pendant l'évaluation :

1. Accédez à l'évaluation
2. Pour chaque contrôle :
   - Testez l'efficacité
   - Documentez les résultats
   - Joignez des preuves
3. Rédigez le rapport d'évaluation
4. Clôturez l'évaluation
