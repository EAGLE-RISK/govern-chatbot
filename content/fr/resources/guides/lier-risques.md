# Lier des Risques

Identifier et gérer les dépendances entre risques pour une vision globale.

- **Niveau :** Avancé
- **Durée de lecture :** 20 min
- **Tags :** Liaison, Dépendances, Relations


## Pourquoi Lier des Risques ?

Lier des risques permet de :
- Identifier les dépendances entre risques
- Comprendre les cascades de risques
- Gérer les risques corrélés

## Étapes pour Lier des Risques

**Localisation** : Gestion des Risques → Liaisons de Risques

**Méthode 1 : Depuis un Risque**
1. Accédez au détail d'un risque
2. Cliquez sur l'onglet **"Liaisons"**
3. Cliquez sur **"Ajouter une liaison"**
4. Sélectionnez le risque à lier
5. Définissez le type de liaison :
   - **Cause → Effet** : Ce risque cause l'autre
   - **Effet → Cause** : Ce risque est causé par l'autre
   - **Corrélation** : Les risques sont corrélés
6. Enregistrez

**Méthode 2 : Depuis la Page Liaisons**
1. Accédez à **Liaisons de Risques**
2. Cliquez sur **"Créer une liaison"**
3. Sélectionnez les deux risques
4. Définissez le type de liaison
5. Enregistrez
