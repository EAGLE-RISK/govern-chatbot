# Configuration Initiale

Checklist complète pour configurer votre organisation dans Govern One.

- **Niveau :** Débutant
- **Durée de lecture :** 30 min
- **Tags :** Configuration, Setup, Organisation


## Checklist de Configuration

Avant de commencer à utiliser Govern One, suivez cette checklist :

#### 1. Compléter le Profil de l'Entreprise
**Localisation**: Paramètres → Profil Entreprise

**Actions à effectuer**:
- [ ] Vérifier le nom de l'entreprise
- [ ] Configurer les départements/activités
- [ ] Définir la devise et la langue

**Guide détaillé**:
1. Accédez à **Paramètres**→ **Profil Entreprise**
2. Complétez tous les champs obligatoires
3. Ajoutez vos départements/activités (ex: Finance, IT, RH, etc.)
4. Enregistrez les modifications

> **Conseil**: Prenez le temps de bien configurer les départements car ils seront utilisés pour organiser vos risques et contrôles.

## Inviter des Utilisateurs

**Localisation**: Administration → Utilisateurs → Inviter

**Actions à effectuer**:
- [ ] Identifier les utilisateurs à inviter
- [ ] Définir leurs rôles et permissions
- [ ] Envoyer les invitations

**Guide détaillé**:
1. Accédez à **Administration**→ **Utilisateurs**
2. Cliquez sur **"Inviter un utilisateur"**
3. Remplissez le formulaire :
- Email de l'utilisateur
- Prénom et nom
- Rôle (Admin, Risk Manager, Utilisateur, etc.)
- Département/Activité
4. Cliquez sur **"Envoyer l'invitation"**
5. L'utilisateur recevra un email avec un lien d'activation

> **Astuce**: Vous pouvez inviter plusieurs utilisateurs en même temps en utilisant la fonction d'import CSV (si disponible).

## Créer un Profil de Risque

**Localisation**: Gestion des Risques → Profils de Risques

**Actions à effectuer**:
- [ ] Créer au moins un profil de risque
- [ ] Configurer la matrice d'évaluation
- [ ] Définir les seuils de criticité

> Consultez le guide détaillé "Créer un Profil de Risque" pour plus d'informations.

## Configurer les Activités/Départements

**Localisation** : Paramètres → Activités

**Actions à effectuer** :
- [ ] Créer les activités principales de l'entreprise
- [ ] Associer les utilisateurs aux activités
- [ ] Définir les responsables

**Guide détaillé** :
1. Accédez à **Paramètres** → **Activités**
2. Cliquez sur **"Ajouter une activité"**
3. Remplissez les informations :
   - Nom de l'activité
   - Description
   - Responsable
   - Utilisateurs associés
4. Enregistrez
