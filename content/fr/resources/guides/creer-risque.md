# Créer un Risque

Processus complet pour créer et évaluer un risque dans Govern One.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 30 min
- **Tags :** Risque, Création, Évaluation


## Vue d'Ensemble

Créer un risque dans Govern One suit un processus structuré qui permet de capturer toutes les informations nécessaires.

**Localisation** : Gestion des Risques → Risques → Créer

## Étapes Détaillées

**Étape 1 : Informations de Base**
1. Cliquez sur **"Créer un risque"**ou **"Ajouter un risque"**
2. Remplissez le formulaire :

**Champs obligatoires**:
- **Nom du risque**: Titre clair et descriptif
- Exemple : "Risque de cyberattaque sur les systèmes informatiques"
- **Description**: Description détaillée du risque
- Inclure : nature, causes potentielles, contexte
- **Profil de risque**: Sélectionnez un profil existant
- **Activité**: Département/activité concerné
- **Type de risque**: Catégorie (stratégique, financier, opérationnel, etc.)

**Champs optionnels**:
- **Risque parent**: Si ce risque est lié à un autre risque
- **Date de fin**: Si le risque a une durée limitée
- **Utilisateurs associés**: Personnes impliquées dans la gestion du risque

3. Cliquez sur **"Suivant"**

**Étape 2 : Évaluation du Risque (Heatmap)**
1. **Sélectionner l'Impact**:
- Cliquez sur une cellule de la heatmap
- L'impact représente les conséquences si le risque se matérialise
- Niveaux : Très faible, Faible, Moyen, Élevé, Très élevé

2. **Sélectionner la Probabilité**:
- La probabilité représente la fréquence d'occurrence
- Niveaux : Très faible, Faible, Moyen, Élevé, Très élevé

3. **Score Automatique**:
- Le score est calculé automatiquement : Score = Impact × Probabilité
- La couleur de la cellule indique la criticité

4. **Visualisation**:
- La heatmap affiche visuellement tous les risques existants
- Les zones rouges indiquent les risques critiques
- Les zones vertes indiquent les risques faibles

**Étape 3 : Propriétaire et Responsables**
1. **Propriétaire du risque**:
- Par défaut : Vous (utilisateur connecté)
- Peut être modifié si nécessaire

2. **Utilisateurs associés**:
- Ajoutez les personnes qui doivent être informées
- Elles recevront des notifications

**Étape 4 : Enregistrer**
1. Vérifiez toutes les informations
2. Cliquez sur **"Créer le risque"**
3. Le risque est créé avec le statut **"Brouillon"**

> **Astuce**: Utilisez les templates de risques depuis les catalogues pour gagner du temps.

## Après la Création

Une fois le risque créé, vous pouvez :
- Ajouter des contrôles
- Planifier des actions de mitigation
- Créer des indicateurs KRI
- Lier à d'autres risques
- Changer le statut (En évaluation → Validé)
