# Planifier une Revue

Organiser des revues périodiques pour maintenir la pertinence des risques.

- **Niveau :** Avancé
- **Durée de lecture :** 25 min
- **Tags :** Revue, Périodique, Validation


## Qu'est-ce qu'une Revue ?

Une **revue** est une évaluation périodique des risques pour :
- Vérifier leur pertinence
- Mettre à jour les évaluations
- Valider les actions de mitigation

## Étapes pour Planifier une Revue

**Localisation** : Gestion des Risques → Revues → Créer

**Étape 1 : Informations Générales**
1. Cliquez sur **"Créer une revue"**
2. Remplissez les champs :
   - **Titre** : Ex: "Revue semestrielle des risques opérationnels"
   - **Description** : Description de la revue
   - **Type de revue** :
     - Revue périodique
     - Revue ad-hoc
   - **Période** : Période couverte par la revue

**Étape 2 : Sélection des Risques**
1. Sélectionnez les risques à revoir
2. Vous pouvez filtrer par :
   - Catégorie
   - Statut
   - Propriétaire
   - Activité

**Étape 3 : Planification**
1. **Date de début** : Date de démarrage
2. **Date de fin** : Date de clôture
3. **Responsable** : Personne en charge
4. **Participants** : Personnes impliquées

**Étape 4 : Enregistrer**
1. Vérifiez les informations
2. Cliquez sur **"Créer la revue"**

## Effectuer une Revue

Pendant la revue :

1. Pour chaque risque :
   - Vérifiez la pertinence
   - Réévaluez si nécessaire
   - Mettez à jour les informations
   - Validez les actions de mitigation
2. Documentez les décisions
3. Clôturez la revue
