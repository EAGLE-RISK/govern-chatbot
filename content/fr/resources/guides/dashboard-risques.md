# Dashboard des Risques

Comprendre et utiliser le tableau de bord des risques pour une vue d'ensemble complète.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 20 min
- **Tags :** Dashboard, Vue d'ensemble, Statistiques


## Accéder au Dashboard

**Localisation** : Gestion des Risques → Dashboard

Le dashboard affiche plusieurs sections :

**1. Vue d'Ensemble**
- Nombre total de risques
- Répartition par statut (Brouillon, En évaluation, Validé, Clôturé)
- Répartition par criticité (Très faible, Faible, Moyen, Élevé, Très élevé)
- Graphiques de tendances

**2. Statistiques par Catégorie**
- Risques stratégiques
- Risques financiers
- Risques opérationnels
- Risques de marché
- Risques technologiques
- Risques projets
- Risques chaîne d'approvisionnement

**3. Actions Rapides**
- Créer un nouveau risque
- Créer un contrôle
- Enregistrer un incident
- Planifier une évaluation

**4. Risques Récents**
- Liste des derniers risques créés ou modifiés
- Accès rapide aux détails

## Personnaliser le Dashboard

Vous pouvez filtrer le dashboard par :
- Période (7 jours, 30 jours, 3 mois, 1 an)
- Statut des risques
- Catégorie de risques
- Propriétaire du risque
- Activité/Département
