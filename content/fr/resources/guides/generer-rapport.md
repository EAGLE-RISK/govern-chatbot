# Générer des Rapports

Créer et exporter des rapports détaillés pour le reporting et les analyses.

- **Niveau :** Avancé
- **Durée de lecture :** 30 min
- **Tags :** Rapport, Export, Analyse


## Types de Rapports Disponibles

1. **Rapport de Risques** :
   - Liste des risques
   - Répartition par catégorie
   - Heatmap des risques

2. **Rapport de Contrôles** :
   - Liste des contrôles
   - Efficacité des contrôles
   - Tests en attente

3. **Rapport d'Incidents** :
   - Liste des incidents
   - Analyse des causes
   - Tendances

4. **Rapport d'Évaluations** :
   - Résultats des évaluations
   - Conformité

5. **Rapport Exécutif** :
   - Vue d'ensemble
   - KPIs clés
   - Recommandations

## Étapes pour Générer un Rapport

**Localisation** : Gestion des Risques → Analyses & Rapports

1. Accédez à **Analyses & Rapports**
2. Sélectionnez le type de rapport
3. Configurez les filtres :
   - Période
   - Catégories
   - Statuts
   - Activités
4. Cliquez sur **"Générer le rapport"**
5. Le rapport s'affiche à l'écran
6. Exportez si nécessaire :
   - PDF
   - Excel
   - PowerPoint
