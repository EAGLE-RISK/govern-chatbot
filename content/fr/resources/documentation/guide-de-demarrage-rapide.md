# Guide de Démarrage Rapide

Apprenez les bases de la plateforme Govern One en quelques étapes simples. Parfait pour les nouveaux utilisateurs.

## Introduction

Bienvenue dans le Guide de Démarrage Rapide de Govern One. Ce guide vous accompagnera dans vos premiers pas avec la plateforme.

**Govern One** est une plateforme complète de gestion de la gouvernance, des risques et de la conformité (GRC) conçue pour simplifier et optimiser vos processus organisationnels.

Dans ce guide, vous apprendrez :
- Comment créer votre compte
- Comment configurer votre profil
- Les fonctionnalités de base
- Comment créer votre premier projet

## Création de votre compte

Pour commencer avec Govern One, vous devez d'abord créer un compte.

**Étapes :**
1. Accédez à la page d'inscription
2. Remplissez le formulaire avec vos informations
3. Vérifiez votre email
4. Connectez-vous à votre compte

Une fois votre compte créé, vous recevrez un email de confirmation avec les instructions pour activer votre compte.
