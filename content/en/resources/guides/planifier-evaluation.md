# Schedule an Assessment

Organize control assessments and audits to ensure compliance.

- **Niveau :** Advanced
- **Durée de lecture :** 35 min
- **Tags :** Assessment, Audit, Compliance


## What is an Assessment?

An **assessment** is a formal review process of risks and controls.

## Types of Assessments

1. **Control Assessment** :
   - Test control effectiveness
   - Compliance verification

2. **Assessment - Audit** :
   - Internal or external audit
   - Regulatory verification

## Steps to Schedule an Assessment

**Location** : Risk Management → Assessments → Create

**Step 1: General Information**
1. Click **"Create an assessment"**
2. Fill in the fields:
   - **Title** : Ex: "Quarterly IT controls assessment"
   - **Description** : Assessment description
   - **Assessment type** :
     - Internal assessment
     - External assessment (Audit)
   - **Associated risk** : Select the risk to assess

**Step 2: Planning**
1. **Start date** : Start date
2. **End date** : Planned closing date
3. **Assessor** : Responsible person
4. **Controls to assess** : Select the concerned controls

**Step 3: Save**
1. Verify information
2. Click **"Create the assessment"**

## Conduct an Assessment

During the assessment:

1. Access the assessment
2. For each control:
   - Test effectiveness
   - Document results
   - Attach evidence
3. Write the assessment report
4. Close the assessment
