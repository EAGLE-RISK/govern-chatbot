# Créer un Indicateur KRI

Mettre en place des indicateurs clés pour surveiller l'évolution des risques.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 25 min
- **Tags :** KRI, Indicateur, Surveillance


## Qu'est-ce qu'un KRI ?

Un **Key Risk Indicator (KRI)** est un indicateur clé qui surveille l'évolution d'un risque.

## Étapes pour Créer un KRI

**Localisation** : Gestion des Risques → Indicateurs KRI → Créer

**Étape 1 : Informations de Base**
1. Cliquez sur **"Créer un KRI"**
2. Remplissez les champs :
   - **Nom du KRI** : Ex: "Nombre d'incidents de sécurité par mois"
   - **Description** : Description de l'indicateur
   - **Risque associé** : Sélectionnez le risque surveillé
   - **Unité de mesure** : Ex: Nombre, Pourcentage, Montant

**Étape 2 : Configuration**
1. **Type de KRI** :
   - Quantitatif : Valeur numérique
   - Qualitatif : Évaluation subjective
2. **Fréquence de collecte** :
   - Quotidien, Hebdomadaire, Mensuel, Trimestriel
3. **Seuils d'alerte** :
   - Seuil vert (Normal) : < X
   - Seuil orange (Attention) : X - Y
   - Seuil rouge (Critique) : > Y

**Étape 3 : Enregistrer**
1. Vérifiez les informations
2. Cliquez sur **"Créer le KRI"**

## Saisir une Valeur KRI

Pour enregistrer une nouvelle valeur :

1. Accédez au KRI
2. Cliquez sur **"Ajouter une valeur"**
3. Remplissez :
- Date de mesure
- Valeur
- Commentaires (optionnel)
4. Enregistrez

> **Astuce**: Configurez des alertes automatiques lorsque les seuils sont dépassés.
