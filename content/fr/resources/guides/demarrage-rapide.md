# Guide de Démarrage Rapide

Première connexion et exploration de l'interface. Apprenez les bases en quelques minutes.

- **Niveau :** Débutant
- **Durée de lecture :** 15 min
- **Tags :** Démarrage, Premiers pas, Connexion


## Première Connexion

#### Étape 1 : Accéder à la Plateforme
1. Ouvrez votre navigateur et accédez à l'URL de Govern One
2. Cliquez sur **"Se connecter"**ou **"Connexion"**
3. Entrez vos identifiants (email et mot de passe)
4. Cliquez sur **"Connexion"**

> **Astuce**: Si vous avez reçu une invitation par email, utilisez le lien fourni pour accéder directement à votre compte.

#### Étape 2 : Compléter votre Profil
Lors de votre première connexion, vous devrez peut-être compléter votre profil :
1. Vérifiez vos informations personnelles
2. Ajoutez votre numéro de téléphone si nécessaire
3. Sélectionnez votre secteur d'activité
4. Cliquez sur **"Enregistrer"**

#### Étape 3 : Explorer le Tableau de Bord
Une fois connecté, vous accédez au **tableau de bord principal**qui affiche :
- Vue d'ensemble de vos risques
- Statistiques clés
- Actions rapides
- Liens vers les fonctionnalités principales

## Navigation dans l'Interface

#### Menu Principal
Le menu latéral (sidebar) contient les sections principales :
- **Dashboard**: Vue d'ensemble
- **Gestion des Risques**: Module principal
- **Paramètres**: Configuration
- **Administration**: Gestion des utilisateurs (si vous avez les droits)

#### Barre de Recherche
Utilisez la barre de recherche en haut pour :
- Rechercher des risques, contrôles, incidents
- Accéder rapidement aux fonctionnalités
- Naviguer vers des pages spécifiques
