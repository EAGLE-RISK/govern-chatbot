# Créer une Action de Mitigation

Planifier et suivre des actions pour réduire les risques identifiés.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 20 min
- **Tags :** Action, Mitigation, Planification


## Qu'est-ce qu'une Action de Mitigation ?

Une **action de mitigation** est une mesure corrective ou préventive pour réduire un risque.

## Étapes pour Créer une Action

**Localisation** : Gestion des Risques → Actions de Mitigation → Créer

**Étape 1 : Informations de Base**
1. Cliquez sur **"Créer une action"**
2. Remplissez les champs :
   - **Nom de l'action** : Ex: "Mise en place d'un système de sauvegarde automatique"
   - **Description** : Description détaillée
   - **Risque associé** : Sélectionnez le risque concerné
   - **Responsable** : Personne en charge de l'action
   - **Date d'échéance** : Date limite de réalisation

**Étape 2 : Planification**
1. **Priorité** :
   - Très élevée, Élevée, Moyenne, Faible
2. **Statut initial** :
   - Planifié, En cours, Terminé, Annulé
3. **Budget estimé** (optionnel)
4. **Ressources nécessaires** (optionnel)

**Étape 3 : Enregistrer**
1. Vérifiez les informations
2. Cliquez sur **"Créer l'action"**

## Suivre une Action

Une fois créée, vous pouvez :
- Mettre à jour le statut (En cours → Terminé)
- Ajouter des commentaires
- Joindre des documents
- Notifier les parties prenantes
