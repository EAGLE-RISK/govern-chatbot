# Initial Setup

Complete checklist to configure your organization in Govern One.

- **Niveau :** Beginner
- **Durée de lecture :** 30 min
- **Tags :** Setup, Configuration, Organization


## Setup Checklist

Before starting to use Govern One, follow this checklist:

#### 1. Complete Company Profile
**Location**: Settings → Company Profile

**Actions to perform**:
- [ ] Verify company name
- [ ] Configure departments/activities
- [ ] Set currency and language

**Detailed guide**:
1. Go to **Settings**→ **Company Profile**
2. Complete all required fields
3. Add your departments/activities (e.g., Finance, IT, HR, etc.)
4. Save changes

> **Tip**: Take time to properly configure departments as they will be used to organize your risks and controls.

## Invite Users

**Location**: Administration → Users → Invite

**Actions to perform**:
- [ ] Identify users to invite
- [ ] Define their roles and permissions
- [ ] Send invitations

**Detailed guide**:
1. Go to **Administration**→ **Users**
2. Click **"Invite a user"**
3. Fill in the form:
- User email
- First and last name
- Role (Admin, Risk Manager, User, etc.)
- Department/Activity
4. Click **"Send invitation"**
5. The user will receive an email with an activation link

> **Tip**: You can invite multiple users at once using the CSV import function (if available).

## Create a Risk Profile

**Location**: Risk Management → Risk Profiles

**Actions to perform**:
- [ ] Create at least one risk profile
- [ ] Configure the assessment matrix
- [ ] Define criticality thresholds

> See the detailed guide "Create a Risk Profile" for more information.

## Configure Activities/Departments

**Location** : Settings → Activities

**Actions to perform** :
- [ ] Create main company activities
- [ ] Associate users with activities
- [ ] Define managers

**Detailed guide** :
1. Go to **Settings** → **Activities**
2. Click **"Add an activity"**
3. Fill in the information:
   - Activity name
   - Description
   - Manager
   - Associated users
4. Save
