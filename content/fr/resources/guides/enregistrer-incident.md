# Enregistrer un Incident

Documenter les incidents et near-misses pour améliorer la gestion des risques.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 30 min
- **Tags :** Incident, Documentation, Analyse


## Qu'est-ce qu'un Incident ?

Un **incident** est un événement qui s'est produit et qui a un impact sur l'organisation.

## Étapes pour Enregistrer un Incident

**Localisation** : Gestion des Risques → Incidents & Pertes → Enregistrer

**Étape 1 : Informations de Base**
1. Cliquez sur **"Enregistrer un incident"**
2. Remplissez les champs :
   - **Titre de l'incident** : Ex: "Panne serveur principale"
   - **Description** : Description détaillée de l'incident
   - **Date d'occurrence** : Quand l'incident s'est produit
   - **Type d'incident** :
     - Incident réel
     - Near-miss (presqu'accident)
   - **Risque associé** : Si l'incident est lié à un risque identifié

**Étape 2 : Impact**
1. **Impact financier** (si applicable) :
   - Montant estimé
   - Devise
2. **Impact opérationnel** :
   - Description de l'impact
   - Durée d'interruption
3. **Impact sur la réputation** :
   - Évaluation (Faible, Moyen, Élevé)

**Étape 3 : Analyse**
1. **Cause racine** :
   - Utilisez la méthode 5 Pourquoi ou Ishikawa
   - Documentez les causes identifiées
2. **Actions correctives** :
   - Actions immédiates prises
   - Actions préventives à mettre en place

**Étape 4 : Enregistrer**
1. Vérifiez toutes les informations
2. Cliquez sur **"Enregistrer l'incident"**

## Analyser un Incident

Après enregistrement, vous pouvez :
- Effectuer une analyse de cause racine (RCA)
- Créer des actions correctives
- Lier à des risques existants
- Générer des rapports d'incidents
