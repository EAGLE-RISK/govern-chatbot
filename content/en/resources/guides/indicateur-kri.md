# Create a KRI Indicator

Implement key indicators to monitor risk evolution.

- **Niveau :** Intermediate
- **Durée de lecture :** 25 min
- **Tags :** KRI, Indicator, Monitoring


## What is a KRI?

A **Key Risk Indicator (KRI)** is a key indicator that monitors the evolution of a risk.

## Steps to Create a KRI

**Location** : Risk Management → KRI Indicators → Create

**Step 1: Basic Information**
1. Click **"Create a KRI"**
2. Fill in the fields:
   - **KRI name** : Ex: "Number of security incidents per month"
   - **Description** : Indicator description
   - **Associated risk** : Select the monitored risk
   - **Measurement unit** : Ex: Number, Percentage, Amount

**Step 2: Configuration**
1. **KRI type** :
   - Quantitative: Numerical value
   - Qualitative: Subjective assessment
2. **Collection frequency** :
   - Daily, Weekly, Monthly, Quarterly
3. **Alert thresholds** :
   - Green threshold (Normal): < X
   - Orange threshold (Attention): X - Y
   - Red threshold (Critical): > Y

**Step 3: Save**
1. Verify information
2. Click **"Create the KRI"**

## Enter a KRI Value

To record a new value:

1. Access the KRI
2. Click **"Add a value"**
3. Fill in:
- Measurement date
- Value
- Comments (optional)
4. Save

> **Tip**: Configure automatic alerts when thresholds are exceeded.
