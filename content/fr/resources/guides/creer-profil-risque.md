# Créer un Profil de Risque

Définir le profil auquel le risque à créer sera associé en fonction de son type et son département.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 10 min
- **Tags :** Profil, Matrice, Évaluation


## Qu'est-ce qu'un Profil de Risque ?

Un **profil de risque** définit :
le profil auquel le risque à créer sera associé en fonction de son type, son département

## Étapes pour Créer un Profil

**Localisation**: Gestion des Risques → Profils de Risques → Créer

**Étape 1 : Informations Générales**
1. Cliquez sur **"Créer un profil"**
2. Remplissez les champs :
- **Nom du profil**: Ex: "Profil Risques Opérationnels"
- **Description**: Description du profil et de son usage
- **Département**: Ex :"DSI"
- **Activité**: Activité de ce département pré sélectionnée
- **Propriétaire**: Ex :"DSI"
3. Cliquez sur **"Suivant"**

**Étape 2 : Enregistrer**
1. Vérifiez toutes les configurations
2. Cliquez sur **"Enregistrer"**
3. Le profil est maintenant disponible pour créer des risques

> **Conseil**: Créez un profil par type de risque (opérationnel, financier, stratégique) pour une meilleure organisation.
