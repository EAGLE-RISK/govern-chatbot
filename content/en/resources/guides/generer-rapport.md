# Generate Reports

Create and export detailed reports for reporting and analysis.

- **Niveau :** Advanced
- **Durée de lecture :** 30 min
- **Tags :** Report, Export, Analysis


## Available Report Types

1. **Risk Report** :
   - List of risks
   - Distribution by category
   - Risk heatmap

2. **Control Report** :
   - List of controls
   - Control effectiveness
   - Pending tests

3. **Incident Report** :
   - List of incidents
   - Cause analysis
   - Trends

4. **Assessment Report** :
   - Assessment results
   - Compliance

5. **Executive Report** :
   - Overview
   - Key KPIs
   - Recommendations

## Steps to Generate a Report

**Location** : Risk Management → Analysis & Reports

1. Go to **Analysis & Reports**
2. Select the report type
3. Configure filters:
   - Period
   - Categories
   - Statuses
   - Activities
4. Click **"Generate report"**
5. The report displays on screen
6. Export if necessary:
   - PDF
   - Excel
   - PowerPoint
