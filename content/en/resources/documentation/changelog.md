# Changelog

History of updates and new features. Follow the evolution of the Govern One platform.

## Introduction

The Changelog documents all changes made to the Govern One platform.

**Types of changes:**
- New features
- Improvements
- Bug fixes
- Security changes
- Interface changes

## Current version

**Version 1.0.0 - First release**

**New features:**
- Initial launch of the Govern One platform
- Complete governance, risk, and compliance (GRC) management
- Interactive dashboard
- Risk management system
- Compliance module
- User and permission management
- Reporting system
- Modern and intuitive user interface

**Main features:**
- Create and manage risk profiles
- Record and track risks
- Define controls and mitigation actions
- KRI (Key Risk Indicators)
- Incident management
- Planning of assessments and reviews
- Custom report generation
- Data export

This first version establishes the foundations of the Govern One platform and offers all essential features for effective governance, risk, and compliance management.
