# Créer un Contrôle

Mettre en place des contrôles pour réduire les risques et tester leur efficacité.

- **Niveau :** Intermédiaire
- **Durée de lecture :** 25 min
- **Tags :** Contrôle, Mitigation, Test


## Qu'est-ce qu'un Contrôle ?

Un **contrôle** est une mesure mise en place pour :
- Réduire la probabilité d'occurrence d'un risque
- Réduire l'impact si le risque se matérialise
- Détecter l'occurrence du risque

## Étapes pour Créer un Contrôle

**Localisation** : Gestion des Risques → Contrôles → Créer

**Étape 1 : Informations de Base**
1. Cliquez sur **"Créer un contrôle"**
2. Remplissez les champs :
   - **Nom du contrôle** : Ex: "Contrôle d'accès aux systèmes"
   - **Description** : Description détaillée du contrôle
   - **Risque associé** : Sélectionnez le risque concerné
   - **Type de contrôle** :
     - Préventif : Empêche l'occurrence
     - Détectif : Détecte l'occurrence
     - Correctif : Corrige après occurrence
   - **Propriétaire** : Responsable du contrôle

**Étape 2 : Configuration**
1. **Fréquence de test** :
   - Quotidien, Hebdomadaire, Mensuel, Trimestriel, Annuel
2. **Méthode de test** :
   - Automatique, Manuel, Mixte
3. **Efficacité attendue** :
   - Très faible, Faible, Moyen, Élevé, Très élevé

**Étape 3 : Enregistrer**
1. Vérifiez les informations
2. Cliquez sur **"Créer le contrôle"**

## Tester un Contrôle

Une fois créé, vous pouvez tester l'efficacité du contrôle :

1. Accédez au contrôle
2. Cliquez sur **"Tester"**
3. Remplissez le formulaire de test :
- Date du test
- Résultat (Efficace, Partiellement efficace, Non efficace)
- Observations
- Preuves/Justificatifs (fichiers joints)
4. Enregistrez le test

> **Conseil**: Testez régulièrement vos contrôles pour vous assurer de leur efficacité continue.
